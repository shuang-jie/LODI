# Posterior summary of the shared-factor AR(1) coefficient

Posterior summary of the shared-factor AR(1) coefficient

## Usage

``` r
posterior_rho(fit)
```

## Arguments

- fit:

  A fitted object returned by
  [`lodi()`](https://shuang-jie.github.io/LODI/reference/lodi.md).

## Value

A numeric vector with elements `mean`, `sd`, `q025`, `q500`, `q975`.
